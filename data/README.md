# Data sources

Both datasets are distributed by the UCI Machine Learning Repository under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
This license applies to the datasets, independently of the project code.

- Yeh, I. (1998). **Concrete Compressive Strength** [Dataset]. UCI Machine Learning Repository.
  DOI: [10.24432/C5PK67](https://doi.org/10.24432/C5PK67).
  [Dataset page](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength).
  `concrete_strength.csv` converts the original Excel table to plain CSV without
  changing its row order, headers or numerical values. Duplicate records are retained.
- Lohweg, V. (2012). **Banknote Authentication** [Dataset]. UCI Machine Learning Repository.
  DOI: [10.24432/C55P57](https://doi.org/10.24432/C55P57).
  [Dataset page](https://archive.ics.uci.edu/dataset/267/banknote+authentication).
  `data_banknote_authentication.txt` is the original numeric data file, unchanged.
